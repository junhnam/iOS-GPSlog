## 共通: Simulate Location の使い方

### Xcode シミュレータでの手動切替

1. Xcode シミュレータでアプリを起動
2. メニュー: `Features → Location → 任意のシナリオ` または `Custom Location...`
3. 「Custom Location」では緯度・経度を直接入力
4. 「Freeway Drive」「City Run」「City Bicycle Ride」など Apple 提供のプリセットシナリオで疑似 GPS が流れる

### GPX ファイルでの自前シナリオ

- Xcode で `New File → GPX File` から GPX を作成し、`Edit Scheme → Run → Options → Default Location` で指定
- 緯度・経度・タイムスタンプの羅列で経路を再現できる

### コマンドラインでの操作（参考）

```bash
xcrun simctl location <device-id> set 35.6812 139.7671   # 単発座標
xcrun simctl location <device-id> clear                   # 解除
```

## Sprint 3: 自宅判定 + 記録モード + お店情報 + 復元エラー

| 確認項目 | Simulate Location 設定 | 期待結果 |
|---|---|---|
| 1. 自宅登録 | 設定タブ → 自宅を登録 → 地図上で適当な点を長押し | 住所が表示されるか、住所取得失敗のメッセージ後に座標で保存可能 |
| 2. 自宅滞在中の停止 | 自宅座標と同じ点に Custom Location 設定 → アプリ起動 → 数分待つ | 経路ラインが伸びない、ピンも立たない |
| 3. 自宅退出時の再開 | Custom Location → Freeway Drive に切替 | 自宅から離れた瞬間に経路ラインが伸び始める |
| 4. トリガーモード | 設定タブ → 記録モードを「トリガー」に → 地図画面に戻る | 右下に緑「記録開始」ボタン。タップで赤「停止」に切替 |
| 5. 復元エラー通知 | （任意）アプリを kill → 再起動して復元失敗を再現 | 画面上部に赤い帯で「今日の記録の復元に失敗しました」と表示 |

## Sprint 4: カレンダー連携 + CSV エクスポート（予定）

| 確認項目 | Simulate Location 設定 | 期待結果 |
|---|---|---|
| 1. カレンダー権限ダイアログ | 設定タブ → カレンダー同期 ON | 「カレンダーへのアクセスを許可しますか？」のシステムダイアログが出る |
| 2. カレンダー選択 | 権限許可後 → 対象カレンダー画面 | 利用可能なカレンダー一覧が出て、選択できる |
| 3. ピン → カレンダー自動作成 | 同一座標を 10 分以上維持してピンを発生させる | 「カレンダー」アプリを開くと、ピンの場所名 / 滞在時間でイベントが作成されている |
| 4. 同期 OFF | 設定タブ → カレンダー同期を OFF にして同様の操作 | カレンダーアプリにイベントが追加されない |
| 5. CSV 今日の記録 | 設定タブ → エクスポート → 「今日の記録だけ書き出す」 | iOS 標準の保存ダイアログが出て、保存先を選べる |
| 6. CSV 全期間 | 設定タブ → エクスポート → 「全期間の記録を書き出す」 | 同上。ファイル名は `gpslog_<日付>.csv` |
| 7. CSV を Excel で開く | 上記 5 / 6 で保存した CSV を Mac の Excel / Numbers で開く | 日本語のお店名が文字化けしない（UTF-8 BOM 効果） |
| 8. CLGeocoder 移行回帰 | Sprint 3 の項目 1 「自宅登録」と同手順 | 住所が表示される。挙動は Sprint 3 と同じ（内部だけ MKReverseGeocodingRequest に変更） |

## 確認時のヒント（jun さん向け）

- **Simulate Location は「実際に動いている」のと同じ扱い**: GPS の更新間隔が完全には実機と一致しないが、滞留判定や経路ライン描画は問題なく動く
- **権限ダイアログは初回のみ出る**: 一度許可 / 拒否を選ぶと iOS が記憶する。リセットしたい時は `Device → Erase All Content and Settings` でシミュレータを初期化
- **カレンダーアプリ**: シミュレータの「カレンダー」アプリを開くと、本機能で追加された予定が確認できる
- **「ファイル」アプリ**: シミュレータの「ファイル」アプリで保存先（オン Mac / iCloud）の確認が可能
- **困ったら停止して相談**: 期待結果と違う動きをしたら、その時点で開発エージェントに「動作が違います」と伝えてください
