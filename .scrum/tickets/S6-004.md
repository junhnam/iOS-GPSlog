## ユーザーストーリー
ユーザー（jun さん）として、DB が 1GB を超えたら古い日付から自動で削除されるようにしたい。なぜなら、長期間使い続けても端末ストレージを圧迫しないようにしたいから。ただし誤削除を避けるため、デフォルトは OFF にして明示的に有効化したい。

## 受け入れ条件

- [x] `Models/AppSettings.swift` に以下を追加:
  - `dbAutoCleanupEnabled: Bool`（デフォルト `false`）
  - `dbAutoCleanupThresholdGB: Double`（デフォルト `1.0`）
- [x] `Services/Storage/DatabaseAutoCleanupService.swift` を新規作成
- [x] `DatabaseAutoCleanupService` の機能:
  - 現在の DB 容量を計測（`FileManager.attributesOfItem` で SwiftData の sqlite ファイルサイズを取得）
  - しきい値超過時に `TripRecord` を `date` 昇順でメモリソートし、しきい値を下回るまで古い順に削除
  - 削除実行は記録停止のたびに 1 回チェック（バックグラウンド常時動作はしない、バッテリー対策維持）
- [x] 設定画面の「データ」セクションに「DB 自動消去」Toggle + しきい値 Stepper（Toggle ON のときのみ表示）を追加
- [x] Toggle OFF 時は `DatabaseAutoCleanupService.cleanup()` が即 `return` して何もしない
- [x] ユニットテスト: しきい値未満（消去なし）/ しきい値超過（古い順削除）/ Toggle OFF（no-op）/ DB 空（no-op）で 4 ケース以上 pass（5 ケース実装済み）

## 技術メモ

### CLAUDE.md 該当要件

> 設定で以下が可能
> ・DB自動消去の有無
>   ・DBに1GB以上のデータが蓄積されている場合に、古い日付データから削除を行う

### 削除タイミング

- 「記録停止のたびに 1 回」が CLAUDE.md のバッテリー対策と整合（バックグラウンド常時動作させない）
- `LocationService.stopTracking()` の最後に `DatabaseAutoCleanupService.cleanup()` を await で呼ぶ
- `cleanup()` は 1 回の呼び出しで複数件削除する可能性あり（しきい値を下回るまでループ）

### DB 容量計測

```swift
let url = ModelContainer.defaultDirectoryURL.appendingPathComponent("default.store")
let attrs = try FileManager.default.attributesOfItem(atPath: url.path)
let bytes = attrs[.size] as? Int64 ?? 0
let gb = Double(bytes) / 1_073_741_824.0
```

### iOS 26 SwiftData 注意

- `.scrum/notes/ios26-swiftdata.md` の「`#Predicate` を避けてメモリフィルタを使う」に従う
- `DailyRecord` を全件取得してメモリで日付ソート → 古い順に削除

### バッテリー対策との整合

- バックグラウンドで定期実行しない（`BGTaskScheduler` も使わない）
- 記録停止トリガーのみ。これにより常時消費は増えない
