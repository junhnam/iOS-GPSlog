## ユーザーストーリー
開発者として、位置情報を一元的に取得できるサービスクラスを使いたい。なぜなら複数の画面・機能から再利用するから。

## 受け入れ条件
- [ ] `Services/Location/LocationService.swift`（仮ディレクトリ）にクラスを作成
- [ ] `CLLocationManager` をラップし、`requestAlwaysAuthorization()` を呼ぶメソッドがある
- [ ] `startUpdatingLocation()` / `stopUpdatingLocation()` を公開
- [ ] 受信した位置情報を `@Published var currentLocation: CLLocation?` で観測可能（`ObservableObject` 準拠）
- [ ] `desiredAccuracy = kCLLocationAccuracyBest`、`distanceFilter = 10`（Sprint 6 で動的調整するためここでは固定）
- [ ] `allowsBackgroundLocationUpdates = true`、`pausesLocationUpdatesAutomatically = true`
- [ ] シミュレータの「Custom Location」または「Freeway Drive」で位置が更新されることを確認

## 技術メモ
- 当面の用途は「現在地表示」と「経路記録」
- DB 保存は Sprint 2 で別チケットにて。ここでは取得とメモリ上の蓄積（最新点配列）のみ
- 経路用に `@Published var route: [CLLocation] = []` も持たせる（S1-007 から参照）
