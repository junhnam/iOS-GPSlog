## ユーザーストーリー
開発者として、Google Maps SDK for iOS をプロジェクトに組み込みたい。なぜなら地図表示・経路描画の基盤になるから。

## 受け入れ条件
- [ ] Swift Package Manager 経由で `GoogleMaps` パッケージが追加されている
- [ ] API キーは `GoogleMaps-Info.plist` または環境変数で読み込み、ハードコードしない
- [ ] `GoogleMaps-Info.plist.example` をコミットしておき、本物はコミットしない（`.gitignore` 追加）
- [ ] `AppDelegate` 相当（または `GPSLoggerApp.init`）で `GMSServices.provideAPIKey(_:)` を呼んでいる
- [ ] `import GoogleMaps` がコンパイル通る
- [ ] README に「API キーの取得・設定方法」を 1 段落で追記

## 技術メモ
- API キーは Google Cloud Console で別途 junさん側で発行が必要 → 取得待ちでもビルドが通るよう、未設定時は警告ログだけ出して落ちないようにする
- SPM のパッケージ URL は `https://github.com/googlemaps/ios-maps-sdk`（公式）
