## ユーザーストーリー
ユーザー（jun）として、立ち寄った場所が自動的にピンとして記録されるようにしたい。なぜなら後から「その日どこに寄ったか」を見返せるようにしたいから。

## 受け入れ条件
- [ ] `GPSLogger/Services/Trip/StayDetector.swift` を新規作成
- [ ] 滞留判定ロジック
  - 直近 10 分以内の座標履歴が、半径 30m 以内に収まっていれば「滞留中」と判定
  - 滞留中は新規 RoutePoint の保存を間引く（同じ場所を何度も記録しない）
  - 滞留終了（半径外への移動を検知）したタイミングで PinRecord を1件作成
  - `PinRecord.stayedFrom` = 滞留判定が始まった時刻、`stayedDurationSeconds` = 滞留時間（秒）
- [ ] しきい値は `struct StayDetectionConfig { let minDuration: TimeInterval = 600; let radiusMeters: Double = 30 }` で管理（後で UI から調整可能になるよう設計）
- [ ] `LocationService` から呼ばれるフックを提供（`StayDetector.ingest(location:) -> StayEvent?` のような API）
- [ ] `LocationService` 側で `StayEvent.stayEnded(pin)` を受けたら `repository.appendPin(pin, to: trip)` で永続化
- [ ] `GPSLoggerTests/StayDetectorTests.swift` を追加
  - 同一点に 10 分以上連続投入 → 滞留中と判定される（`StayEvent.staying`）
  - 滞留中に 30m 外の点を投入 → `StayEvent.stayEnded(pin)` が返る、pin の座標は滞留中心、duration が約10分
  - 9分間しか同一点に居ない場合 → ピンは作成されない
  - 滞留中の RoutePoint は間引かれる（`StayEvent.skipped`）

## 技術メモ
- 滞留中心は最初の点の座標をそのまま使う（簡易実装）。重心計算は Sprint 6 で精緻化
- 10分というしきい値は CLAUDE.md 要件、30m は GPS 精度（kCLLocationAccuracyBest = 約 5〜10m）に揺らぎマージンを足した値
- 自宅滞在時の記録停止は Sprint 3 で別途対応（このチケットでは「自宅でない場所での滞留」を一律ピン化する）
- お店情報の紐付け（placeName/placeURL）は Sprint 3 の MKLocalSearch 連携で別チケット。本チケットでは座標と滞留時間のみ保存
