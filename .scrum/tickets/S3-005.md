## ユーザーストーリー
ユーザーとして、トリガーモードの時だけ地図画面に「記録開始 / 停止」ボタンが現れ、押すと記録が始まったり止まったりしてほしい。なぜなら、自分のタイミングで記録を制御したいからである。

## 受け入れ条件
- [ ] `Features/Map/RecordingToggleButton.swift` を新規作成。`MapView` に `.overlay` で右下に配置（フローティング）
- [ ] `AppSettings.recordingMode == .trigger` のときのみ表示。`.continuous` では非表示
- [ ] ボタンは記録中（`LocationService.isLogging == true`）と停止中で文言と色が変わる
  - 停止中: 「記録開始」緑系
  - 記録中: 「停止」赤系
- [ ] タップで `LocationService.start()` または `stop()` を呼ぶ
- [ ] 自宅滞在中（HomeState.atHome）にトリガー記録を開始した場合は、自宅を出るまで実際の点は保存されないことを HUD 文言で 1 度だけ警告表示（後続スプリントで詳細化、Sprint 3 では文言のみ）
- [ ] アプリ再起動時、トリガーモードでは記録が自動再開されない（手動で押す必要がある）
- [ ] ユニットテスト: ボタンタップで `LocationService` のメソッドが呼ばれる（モック）

## 技術メモ
- `LocationService` に `var isLogging: Bool { get }` を公開（既存にあれば流用）
- ボタンの状態購読は `@Observable` の `AppSettings` と `LocationService` を `@Environment` 経由で取得
- iOS 26 SwiftData: 該当なし
