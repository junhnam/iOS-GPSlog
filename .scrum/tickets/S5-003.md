## ユーザーストーリー
ユーザーとして、設定画面でクラウド同期の保存先（Google Drive / Dropbox / なし）を選び、選んだサービスに対して認証を行いたい。なぜなら、自分が使いたいクラウドサービスを明示的に選べないと、勝手にどこかに保存される不安があるから。

## 受け入れ条件

- [ ] `Features/Settings/CloudStoragePickerView.swift` を新規作成
- [ ] 設定画面の「データ」セクションに「クラウド同期先」エントリを追加
- [ ] 選択肢: 「なし」「Google Drive」「Dropbox」の 3 つから 1 つ選択（Sprint 5 で Dropbox を入れない場合は 2 つ）
- [ ] 「Google Drive」を選ぶと、未認証なら `GoogleDriveSyncService.authenticate()` が起動。認証成功でアカウント名（Email）が表示される
- [ ] 「Dropbox」も同様（取り込まれる場合）
- [ ] 「なし」を選ぶと、認証済みのプロバイダから `signOut()` を呼びトークンを Keychain から削除
- [ ] `AppSettings.cloudProviderKind: CloudProviderKind?` を追加（Optional・nil = 未設定）
- [ ] ユニットテスト: 選択変更時に AppSettings が更新される / 認証成功でアカウント名が表示される / signOut 経路の 3 ケース以上

## 技術メモ

- S4-007（ExportView）と同じく、@MainActor クロージャ注入で疎結合に組み立てる（テスタビリティのため）
- 認証中は `ProgressView` を出し、ボタンを disable
- 認証エラー時は `Alert` でエラーメッセージを表示（`GoogleDriveSyncError` / `DropboxSyncError` の `errorDescription` を使う）
- iOS 26 の SwiftUI で `Picker` の `pickerStyle(.menu)` を使うと選択 UI がコンパクト
