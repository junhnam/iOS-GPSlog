## ユーザーストーリー
ユーザーとして、自宅位置を地図上で指定し、住所を確認して登録したい。なぜなら、自宅にいる間は GPS 記録を止めて電池を節約したいからである。

## 受け入れ条件
- [ ] 設定画面の「自宅」セクションから「自宅を登録」ボタンを押すと地図ピッカー（`HomeRegistrationView.swift`）が開く
- [ ] 初期表示は「現在地」（権限が無ければ東京駅 35.6812,139.7671）
- [ ] 地図上のピンをドラッグまたは「現在地に合わせる」ボタンで自宅候補座標を変更できる
- [ ] 候補座標から逆ジオコーディング（CLGeocoder.reverseGeocodeLocation）で住所文字列を取得し、画面下部に表示
- [ ] 住所候補が複数返る場合は List で 3 件まで表示し、jun さんが選択できる（タップで決定）
- [ ] 「保存」ボタンで `AppSettings.homeLocation` に書き込み、設定画面に戻る
- [ ] 「半径」スライダー（50m〜300m, デフォルト 100m）で `homeRadiusMeters` も同時に保存
- [ ] 保存済みの自宅がある場合、設定画面に「住所」「緯度経度」「半径」が表示される
- [ ] 「自宅を解除」ボタンで `homeLocation` を nil に戻せる
- [ ] ユニットテスト: 逆ジオコーディング失敗時に住所が空でも保存可能、半径の境界値（50/300）

## 技術メモ
- CLGeocoder は MainActor 隔離不要だが、コールバックは Main で処理する
- 地図表示は Sprint 1 で導入済の Google Maps SDK を流用。マーカー 1 個 + 円（半径表示）
- 住所表示は `CLPlacemark` の `name`, `thoroughfare`, `locality`, `administrativeArea`, `postalCode` を組み立て
- ネットワークエラー時は「住所取得に失敗しました（位置のみ保存します）」を表示

## 平易な補足（jun さん向け）
地図上で「ここが自宅」とピンを置いて、住所も確認できる画面を作ります。住所は逆ジオコーディング（緯度経度から住所を引く iOS 標準機能）で自動取得します。
