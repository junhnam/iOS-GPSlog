## ユーザーストーリー
ユーザーとして、自動同期を ON にしている時は「記録停止 → クラウドストレージに自動的に CSV がアップロードされる」状態にしたい。なぜなら、毎日明示的にエクスポート操作をしなくても、出かけた日の記録が後から振り返れる場所に勝手に保存されているのが理想だから。

## 受け入れ条件

- [ ] `Services/Cloud/CloudUploadCoordinator.swift` を新規作成
- [ ] 記録停止時のトリガー（既存の LocationService の停止経路 / トリガーモードの停止ボタン押下経路 / 自宅到達による自動停止経路）から `CloudUploadCoordinator.uploadIfEnabled(for: tripRecord)` を呼ぶ
- [ ] アップロード階層: `GPSログ/{YYYY-MM-DD}/data.csv`
  - `{YYYY-MM-DD}` は `tripRecord.date` を `Locale(identifier: "en_US_POSIX")` でフォーマット
  - フォルダが存在しない場合は事前に作成（Google Drive / Dropbox とも API がある）
  - 同一パスに既にファイルがある場合は上書き（同日内で複数回記録停止する想定）
- [ ] アップロード対象データ: `CSVExportService.export(trips: [tripRecord])` の結果（S4-005 の既存 API を利用）
- [ ] アップロード前提: `AppSettings.cloudAutoSyncEnabled == true && AppSettings.cloudProviderKind != nil`
- [ ] ユニットテスト: 自動同期 ON 時のアップロード呼び出し / 自動同期 OFF 時の非呼び出し / プロバイダ未設定時の非呼び出し / 同一パス上書き / フォルダ作成経路の 5 ケース以上

## 技術メモ

### CloudUploadCoordinator の責務

```swift
@MainActor
final class CloudUploadCoordinator {
    private let providers: [CloudProviderKind: CloudStorageProvider]
    private let settings: AppSettings
    private let csvExporter: CSVExportService

    func uploadIfEnabled(for trip: TripRecord) async {
        guard settings.cloudAutoSyncEnabled,
              let kind = settings.cloudProviderKind,
              let provider = providers[kind] else { return }

        let csvData = csvExporter.export(trips: [trip])
        let path = "GPSログ/\(formatDate(trip.date))/data.csv"
        do {
            _ = try await provider.uploadCSV(csvData, toPath: path)
        } catch {
            // S5-006 のリトライキューに渡す
            await retryQueue.enqueue(trip: trip, error: error)
        }
    }
}
```

### 記録停止トリガーへの組み込み

LocationService または HomeDetector の「記録停止」遷移ハンドラから `Task { await coordinator.uploadIfEnabled(for: trip) }` を呼ぶ。

### iOS 26 / Swift 6 strict concurrency

- `CloudUploadCoordinator` は `@MainActor`（AppSettings の読み込みが MainActor 必須のため）
- 内部のアップロード処理は `Task` で切り出し、Bridge は `await` 経由
