## ユーザーストーリー
ユーザー（jun さん）として、ホーム画面で他のアプリと並んだ時に「これは GPS 記録アプリだ」とすぐ分かるアイコンと、起動時に違和感のないローンチスクリーンが欲しい。なぜなら、個人利用とはいえ自分の iPhone で毎日使うアプリなので、見た目で苛立たないように整えたいから。

## 受け入れ条件

### Designer フェーズ（メインから scrum-designer エージェント起動）

- [x] 1024x1024 マスターアイコン: SwiftUI で生成する `IconDesignPreview.swift` を提供（Designer は画像生成不可のため SwiftUI Preview から書き出す方式）。デザイン方針: S字カーブ移動経路 + 目的地ピン + 現在地ドット、配色は深藍 #1A3A5C → 青 #2E7FC0 の対角グラデーション
- [x] デザイン方針: 個人利用版なので落ち着いた配色（青系トーン）/ GPS / 移動 / 地図を連想させる図像
- [x] iOS 全サイズ: iOS 14+ では 1024x1024 single-size 構成で OK（Contents.json で `single-size: true` 相当）
- [x] ローンチスクリーン: Info.plist `UILaunchScreen` 辞書方式で背景色 `LaunchBackground`（#1A3A5C）

### Dev-1 反映フェーズ（メイン代行）

- [x] `Resources/Assets.xcassets/AppIcon.appiconset/Contents.json` を更新（PNG ファイル名 `AppIcon-1024.png` 明記）
- [x] **placeholder PNG（Designer 配色のグラデーション + 中央ピン簡易表現）**を Swift CLI（AppKit/CoreGraphics）で生成し `AppIcon-1024.png` として配置（jun さんは後で `IconDesignPreview.swift` から書き出した本番 PNG に差し替え可能、手順は `.scrum/notes/icon-export-howto.md` 参照）
- [x] `xcodebuild clean build`: missing icon warning 0 確認済
- [x] ローンチスクリーン実装: Info.plist `UILaunchScreen` で `LaunchBackground` colorset を指定（storyboard 不要、SwiftUI ベース）
- [x] 既存ユニットテスト 204/204 pass（UI のみ変更のため回帰なし確認済）
- [x] 副次対応: `SettingsView.swift` の `#Preview` で `return` 文後に `_ = container` がある dead code warning を解消
- [ ] 実機での見た目確認は S6-008 で実施

## 技術メモ

### Designer エージェントへの依頼内容（メインがエージェント起動時に渡す）

```
プロダクト: iOS GPS ロガーアプリ（個人利用版）
配布形態: jun さん自身の iPhone 16 Pro に Xcode 直インストール
配色方針: 落ち着いた配色、ホーム画面で他のアプリと並んでも違和感がない
モチーフ: GPS / 移動 / 地図 / 経路を連想させる図像
回避: 派手な色、商用アプリ感の強いデザイン、iOS デフォルトアイコンと類似
出力:
- 1024x1024 マスター PNG
- iOS 全サイズ展開 PNG セット
- ローンチスクリーン配色 / ロゴ配置案 1 案
保存先: jun さんに渡す形（メインが受け取って Dev-1 に橋渡し）
```

### App Store 申請関連は除外

- jun さん指示で個人利用版のみ → App Store 申請メタデータ不要
- ただし将来商用化判断時に再利用できるよう 1024x1024 マスターは保存しておく（再生成コスト削減）

### Free Provisioning でのアイコン制約

- Free Provisioning でも全サイズアイコンが必要（不足時は Xcode が警告）
- TestFlight 配布は不要なので App Store Connect 登録は不要
