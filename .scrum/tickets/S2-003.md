## ユーザーストーリー
開発者として、TripRecord に対する取得・作成・更新を一箇所に集約した API を呼びたい。なぜなら LocationService や履歴画面など複数箇所からDBアクセスが発生するから。

## 受け入れ条件
- [ ] `GPSLogger/Services/Persistence/TripRepository.swift` を新規作成
- [ ] 以下のメソッドを公開（全て `@MainActor` 前提）
  - `func todayTrip(creatingIfMissing: Bool) throws -> TripRecord`：当日 0 時の TripRecord を取得、無ければ新規作成
  - `func trip(on date: Date) throws -> TripRecord?`：指定日付の TripRecord を取得（無ければ nil）
  - `func recentTrips(limit: Int = 30) throws -> [TripRecord]`：直近30日分（降順）
  - `func appendRoutePoint(_ location: CLLocation, to trip: TripRecord) throws`：RoutePoint を追加して trip に関連付け
  - `func appendPin(_ pin: PinRecord, to trip: TripRecord) throws`：PinRecord を追加して trip に関連付け
  - `func updateEnd(of trip: TripRecord, at date: Date) throws`：endedAt を更新
  - `func updateTotalDistance(of trip: TripRecord, addingMeters meters: Double) throws`：累積距離を加算保存
- [ ] エラーは `enum TripRepositoryError: Error` を定義し、`fetchFailed`、`saveFailed(underlying: Error)` などの case を持つ
- [ ] `GPSLoggerTests/TripRepositoryTests.swift` を追加し、以下を検証
  - `todayTrip(creatingIfMissing: true)` 初回呼び出しで TripRecord が作成される
  - 2回目の呼び出しでは同じ TripRecord を返す（重複作成なし）
  - `appendRoutePoint` 後、`trip.routePoints.count` が増える
  - `updateTotalDistance` で累積される（100m + 200m = 300m）

## 技術メモ
- 当日0時の判定は `Calendar.current.startOfDay(for: Date())` を使う
- リポジトリは `init(modelContext: ModelContext)` で DI 可能にする（テストでインメモリコンテキストを注入）
- 本番では `PersistenceController.shared.container.mainContext` を使う
- 日付が変わった瞬間の自動切替は **このチケットでは扱わない**（S2-005 の連携処理側で「現在の日付が trip.date と異なれば新しい trip を取り直す」と書く）
