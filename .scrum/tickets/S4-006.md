## ユーザーストーリー
ユーザーとして、CSV ファイルの保存先を自分で選びたい。なぜなら、iCloud Drive の特定フォルダや「ファイル」アプリの任意の場所に整理して保存したいからである。

## 受け入れ条件
- [ ] `GPSLogger/Features/Export/DocumentPickerView.swift` を新規作成。`UIViewControllerRepresentable` で `UIDocumentPickerViewController(forExporting:asCopy:)` をラップ。
- [ ] 入力: `[URL]`（S4-005 が返す一時ファイル URL の配列）/ 出力: 保存成功時のコールバック（保存先 URL）/ キャンセル時のコールバック（nil）。
- [ ] `asCopy: true` で開く（一時ファイルを移動せずコピーする運用）。
- [ ] iOS 17+ 推奨の `forExporting` イニシャライザを使用（`forExporting:asCopy:`）。
- [ ] SwiftUI 側からの呼び出しは `.sheet` または `.fileExporter` の選択：今回は SwiftUI 標準 `.fileExporter(isPresented:document:contentType:defaultFilename:onCompletion:)` を**第一候補**とし、より細かい制御が必要なら UIDocumentPickerViewController ラップにフォールバック。
- [ ] 保存後にユーザーへ「保存しました」のトースト or アラートを表示するためのコールバックを呼び出し元（S4-007）に渡す。
- [ ] ユニットテスト最低 2 ケース: (a) 保存成功で URL が返る、(b) キャンセルで nil が返る（DocumentPicker のスタブ実装での検証）。

## 技術メモ
- SwiftUI の `.fileExporter` は iOS 16+ で標準提供されており、UIDocumentPickerViewController を直接ラップするより簡潔に実装できる。`FileDocument` プロトコル準拠の薄いラッパーを定義する。
- `CSVExportDocument: FileDocument` を `Features/Export/` に作成し、`init(configuration:)` と `fileWrapper(configuration:)` を実装。`UTType.commaSeparatedText` を `readableContentTypes` / `writableContentTypes` に指定。
- `defaultFilename` は `gpslog_<日付>.csv` の形式で動的に生成。
- ユニットテストは `FileDocument` の `fileWrapper` 出力が CSV バイト列になることを検証する程度で十分。`.fileExporter` の UI 自体のテストは Sprint 5 以降の実機テストで補完。

## 平易な補足（jun さん向け）
CSV ファイルを「ファイル」アプリ経由で iCloud Drive やローカルの好きな場所に保存できるようにします。iOS 標準の保存ダイアログ（写真を別アプリで保存する時に出るアレ）を使います。保存先として Google Drive アプリがインストールされていれば、そこも選べます。
