## 技術メモ

### Google Drive と共通化する抽象

S5-001 と本チケットで以下の共通プロトコルを定義し、上位レイヤー（S5-005 自動アップロード）はプロトコル経由でアクセスする:

```swift
protocol CloudStorageProvider: Sendable {
    var providerKind: CloudProviderKind { get } // .googleDrive / .dropbox
    func authenticate() async throws -> CloudAccount
    func signOut()
    func uploadCSV(_ data: Data, toPath path: String) async throws -> CloudFile
}

enum CloudProviderKind: String, Codable, Sendable {
    case googleDrive
    case dropbox
}
```

これにより S5-003（保存先選択 UI）と S5-005（自動アップロード）は、ユーザーが選んだプロバイダに応じて `[CloudStorageProvider]` から適切な実装を取り出して使える。

### 機密情報の扱い

- Dropbox App Key（iOS 用）は機密情報ではない（公開しても問題ない）
- App Secret はモバイル iOS では PKCE フローで発行不要
- アクセストークン / リフレッシュトークンは Keychain 保存

### iOS 26 / Swift 6 strict concurrency

- `DropboxSyncService` は actor または `Sendable` 構造体ベース
- `DropboxAccount` / `DropboxFile` は `Sendable` 準拠
