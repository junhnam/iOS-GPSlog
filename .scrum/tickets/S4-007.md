## ユーザーストーリー
ユーザーとして、設定画面または履歴画面から「CSV を書き出す」操作をしたい。なぜなら、エクスポートしたいタイミング（旅行の後など）に明確なエントリポイントがほしいからである。

## 受け入れ条件
- [ ] `GPSLogger/Features/Export/ExportView.swift` を新規作成。SwiftUI で 2 つのオプションを提供:
  - 「今日の記録だけ書き出す」（`exportTripRecord(_:)` を呼ぶ）
  - 「全期間の記録を書き出す」（`exportAllTrips()` を呼ぶ）
- [ ] 各オプションは Button + ProgressView（書き出し中はローディング表示）+ 完了後に `.fileExporter` を起動。
- [ ] 設定画面の「データ」セクションに「エクスポート」NavigationLink を追加し、`ExportView` を遷移先にする。
- [ ] エクスポート対象が 0 件の場合は Button を disabled にし、「記録がまだありません」を表示。
- [ ] エクスポート成功 / キャンセル / 失敗それぞれで Toast または Alert で結果を通知する。
- [ ] ExportView は `CSVExportService` を `@MainActor` プロパティとして注入できる設計（テスト時はフェイクを差し込む）。
- [ ] ユニットテスト最低 3 ケース: (a) 今日の記録ボタン押下で exportTripRecord が呼ばれる、(b) 全期間ボタン押下で exportAllTrips が呼ばれる、(c) 0 件で disabled 状態。

## 技術メモ
- 設定画面（`SettingsView`）の Section レイアウトは Sprint 3 で確立済。「データ」セクションを既存の「自宅 / 記録モード / カレンダー同期」の下に追加する。
- ExportView のナビゲーションタイトルは「エクスポート」。トップに簡単な説明文「CSV ファイルとして書き出します。Excel やスプレッドシートで開けます。」を表示。
- `.fileExporter` の onCompletion で Result を受け取り、Toast 表示は `@State var resultMessage: String?` + `.alert` で実装。
- 進行中のローディングは Task で `await csvExportService.exportAllTrips()` を呼び、`@State var isExporting: Bool` で制御する。
- Sprint 3 の RestoreErrorTests と同じ流儀で「成功 / 失敗 / dismiss」のテストパターンを揃える。

## 平易な補足（jun さん向け）
「設定 → エクスポート」のメニューから、CSV を書き出すための専用画面を作ります。「今日の記録」と「全期間の記録」の 2 つのボタンが並びます。押すと iOS 標準の保存ダイアログが出て、保存先を選べます。書き出し中はクルクル表示が出て、終わると「保存しました」のメッセージが表示されます。
