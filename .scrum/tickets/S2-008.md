## ユーザーストーリー
ユーザー（jun）として、過去の遠出を「日付ごとに」一覧から選んで、その日の地図・ピン・移動距離を見返せるようにしたい。なぜなら数日前の旅行で「どの店に寄ったか」をふと思い出したいときがあるから。

## 受け入れ条件
- [ ] `GPSLogger/Features/History/HistoryListView.swift` を新規作成
  - 既存の TabView の「履歴」タブから遷移（Sprint 1 の RootView で枠は確保済み）
  - 直近 30 日分の TripRecord を `recentTrips(limit: 30)` から取得し、降順でリスト表示
  - 各行: 日付（yyyy/MM/dd 形式）、開始〜終了時刻、総移動距離（X.XX km）、ピン件数（X 件）
  - リストが空のときは「まだ記録がありません」と中央表示
- [ ] `GPSLogger/Features/History/HistoryDetailView.swift` を新規作成
  - リストから日付タップで遷移
  - 当日の経路（polyline）+ ピン群（GMSMarker）を地図表示
  - 画面上部または下部に「総移動距離 X.XX km」「滞留 X 件 / 合計 Y 分」を表示
  - ピンタップで「滞留 約 N 分」だけは表示する（placeName は Sprint 3 で連携）
- [ ] 履歴詳細の地図初期表示は当日の経路全体が収まる範囲（fitBounds 相当）
- [ ] 履歴一覧の最大表示は **直近 30 日**（Sprint 5 で「全期間表示」「日付フィルタ」を別チケットで対応）
- [ ] `GPSLoggerTests/HistoryViewModelTests.swift`（VM があれば）or 同等のロジックテストで以下を検証
  - 3 日分の TripRecord（各日違う距離）を投入後、リスト VM が降順 3 件を返す
  - 各行の表示文字列（距離・ピン件数）が期待値と一致

## 技術メモ
- 地図描画コンポーネントは S1-006 の `MapView`（GMSMapView ラッパー）を再利用。Polyline と Marker の流し込み API を再利用できるよう、必要なら共通化リファクタを軽く行う
- 日付フォーマットは DateFormatter のキャッシュを使う（行数が増えても性能影響を抑えるため）
- 履歴詳細での polyline は「再描画」用パスを使う（差分 append ではなく一括投入）
- iOS 26 SwiftUI の `NavigationStack` を使用
- 自宅・お店情報・カレンダー連携（タップでカレンダーアプリへ）は Sprint 3〜4 の対応。本チケットでは座標と滞留時間のみで OK
