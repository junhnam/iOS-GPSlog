## ユーザーストーリー
ユーザーとして、操作しやすい画面で地図と記録ボタンを使いたい。なぜなら運転中などにも使う可能性があり、視認性が重要だから。

## 受け入れ条件
- [x] `Design/Mockups/MainScreenMock.swift` に SwiftUI プロトタイプを作成（実機能は持たないダミーでよい）
- [x] 構成要素: ① 全画面の地図プレースホルダ、② 上部にステータスバッジ（「記録中」「停止中」のダミー）、③ 右下に大きめのフローティングボタン（記録 ON/OFF 切替の見た目）、④ 下部にタブバー（地図／履歴／設定）
- [x] カラースキーム案: プライマリ #1E88E5、危険 #E53935、ニュートラル背景 #F5F5F5
- [x] フォント: SF Pro Default、最小 14pt（caption2 11pt のラベル補助は非テキスト要素扱い。本文は 14pt 以上）
- [x] ライト／ダークモード両対応のプレビューが付いている (`#Preview`)
- [ ] スクリーンショット 2 枚（ライト・ダーク）を `Design/Mockups/` 直下に PNG で添付 ※環境制約により未対応
- [x] アクセシビリティ: フローティングボタンに `accessibilityLabel("記録開始/停止")` を付与

## 技術メモ
- 実機能は Dev チームが Sprint 1〜3 で順次実装
- このモックは「合意形成」用なので、Hardcoded データで OK
- 1ファイルにまとめ、Dev のファイル群と競合しないこと

### 実装上の追加メモ（Designer から Dev への申し送り）
- カラー/スペーシング/角丸は `MockColor` / `MockSpacing` / `MockRadius` の private enum で定義済み。
  Sprint 3 以降で `Design/Tokens/DesignSystem.swift` のような共通モジュールに昇格する想定。
- 状態遷移は `RecordingState`（recording / stopped / atHomeIdle）で表現。
  `atHomeIdle` は CLAUDE.md の「自宅滞在中は記録停止」に対応する第3状態。
- 記録ボタンは押下で `recording ⇄ stopped` を切替（`atHomeIdle` 中は recording に復帰）。
  実装時は ViewModel から State を注入する形に置換する。
- 地図エリアはダミーのグリッドラインと `Color #1E88E5` のベジエ曲線で
  「Sprint 1 ゴールである青い経路ライン」のイメージを擬似表現している。
  Google Maps SDK 統合時は `mapPlaceholder` を `GoogleMapView` に差し替えるだけで足りる構造。
- 受け入れ条件のスクリーンショット 2 枚は、本セッション環境に Xcode 本体が無く Canvas プレビューを
  画像化できないため未添付。jun さん側で `open MainScreenMock.swift` → Canvas → ⌘+Shift+P
  で 2 枚保存いただきたい（フォローアップ）。

### スクリーンショット手順（Sprint 1 のフォローアップ作業）
1. Xcode で `MainScreenMock.swift` を開く
2. Canvas を表示（⌘+Option+Return）
3. 「Light - 記録中」プレビューにマウスオーバー → カメラアイコン → Export Preview Image
4. 同様に「Dark - 記録中」もエクスポート
5. `GPSLogger/Design/Mockups/main-light.png`, `main-dark.png` として保存
