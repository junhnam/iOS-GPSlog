## ユーザーストーリー
PO/SM として、シミュレータでは検証できない項目を jun さんの iPhone 16 Pro / iOS 26.1 実機で総合確認したい。なぜなら、Sprint 6 完了 = 個人利用版リリース可能の判定には、MKLocalSearch のお店名検索精度・SLC のバックグラウンド起動・バッテリー実測・アイコンの実機表示が実機でないと確認できないから。

## 受け入れ条件

### PO/SM 事前準備

- [ ] Sprint 6 内の全 Dev チケット (S6-001 〜 S6-007 / S6-009) が Done 状態
- [ ] メイン代行が `xcodebuild clean build` / `xcodebuild clean test` で warning 0 / error 0 / 全ユニットテスト pass を確認済
- [ ] jun さん向け実機検証チェックリストを作成（このチケットの「実機検証 7 観点」を Markdown / 印刷可能な形式で）

### jun さん実施（PO/SM が依頼 + 結果を集約）

- [ ] **観点 1: Xcode → 実機インストール**
  - Xcode Project を開き、Free Provisioning（Personal Team）で署名
  - iPhone 16 Pro を USB / Wi-Fi 接続
  - Run でビルド + 実機インストール成功
  - ホーム画面にアプリアイコン表示
- [ ] **観点 2: MKLocalSearch（ピン名前付け）**
  - 適当な場所（コンビニ / 飲食店）に 10 分以上滞在 → ピン記録
  - ピンに「お店の名前」と「住所」が表示される
  - 表示されない場合は座標表示にフォールバックするか確認
- [ ] **観点 3: SLC バックグラウンド**
  - アプリを背景に回した状態で 500m 以上移動（運転 or 徒歩）
  - 戻った時に経路が記録継続している
  - 必要に応じて kill 状態（ホームバーから上スワイプで終了）からも再現確認
- [ ] **観点 4: バッテリー実測**
  - 1 時間運転（または 1 時間散歩 / 自転車）で記録 ON のまま
  - 開始時 / 終了時のバッテリー% を記録 → 消費 5% 以下が目標
  - 結果を S6-008 のコメントに jun さんが記入
- [ ] **観点 5: バックグラウンド復帰**
  - アプリを背景化 → 数分後に戻す → 記録が破綻なく続いている
  - 日付跨ぎ（23:55 開始 → 0:05 復帰）で新規 DailyRecord が生成される
- [ ] **観点 6: アイコン実機表示**
  - ホーム画面のアイコンが S6-007 で生成したデザイン通り
  - 設定 → アプリ一覧でも正しく表示
  - しっくり来る / 来ないの判断を jun さんが記入
- [ ] **観点 7: ローンチスクリーン**
  - アプリ起動時の表示が違和感ない
  - 起動 → メイン画面遷移がスムーズ

### 失敗時の対応

- [ ] 観点 2 失敗（MKLocalSearch 精度低）: 個人利用版なので「住所のみ表示」にフォールバックして許容。Sprint 6 完了後の追加コミットで対応 or DEFER
- [ ] 観点 4 失敗（バッテリー消費過大）: S6-005 の動的精度しきい値を再調整 → 再ビルド → jun さんに再実測依頼。Sprint 内 2 周まで対応
- [ ] 観点 6 失敗（アイコンしっくり来ない）: Designer に再依頼。Sprint 6 完了後の追加コミットで差し替え
- [ ] その他失敗: Sprint 内修正 or Sprint 6 review 時にユーザー合意で DEFER 判断

## 技術メモ

### Free Provisioning の制約

- 7 日間で署名期限切れ → 再ビルドで対応
- バックグラウンド実行は許可される（Apple Developer Program 加入時と同じ動作）
- TestFlight 配布は不可（個人利用版なので不要）

### 実機検証で判明する可能性のある問題と対処

| 想定問題 | 原因の可能性 | 対処 |
|---|---|---|
| ホーム画面でアイコンが「default」表示 | Assets.xcassets 反映漏れ | S6-007 修正コミット |
| 起動直後にクラッシュ | DI 漏れ（Sprint 4/5 と同型）| RootViewIntegrationTests に統合テスト追加 + 修正 |
| バックグラウンドで記録が止まる | UIBackgroundModes 設定漏れ / `allowsBackgroundLocationUpdates = false` | Info.plist / LocationService 確認 |
| 1 時間で 15% バッテリー消費 | `desiredAccuracy = best` から切り替わっていない | S6-005 のしきい値調整 |
