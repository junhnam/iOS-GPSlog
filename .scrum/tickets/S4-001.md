## ユーザーストーリー
開発者として、iOS 26 で deprecated になった `CLGeocoder` を `MKReverseGeocodingRequest` へ移行したい。なぜなら、ビルド warning が将来のリリースビルドで顕在化する前に消し、API 変更の影響を最小範囲に閉じ込めたいからである。

## 受け入れ条件
- [ ] `GPSLogger/Features/Settings/HomeRegistrationView.swift` の `CLGeocoder` 利用を `MKReverseGeocodingRequest` に置き換える（プロパティ `geocoder` の削除、`triggerReverseGeocode(coordinate:)` の本体差し替え、`cancelGeocode` 相当のキャンセル処理を `Task` の `cancel()` に切替）。
- [ ] `GPSLogger/Services/Place/PlaceLookupService.swift` の `AppleGeocoder.reverseGeocode(location:)` を `MKReverseGeocodingRequest` ベースの実装に置き換える（`GeocoderPerforming` プロトコルのインタフェースは String? のままで維持）。
- [ ] フル再コンパイル（`xcodebuild -clean -build` 等）で `'CLGeocoder' was deprecated` の warning が **0 件**になる（QA-S3-002 で確認した 1 件が消えること）。
- [ ] 既存ユニットテストが回帰なし（79 / 79 pass を維持。HomeRegistration / PlaceLookup 周辺の既存テストはモック差し替えで通る設計）。
- [ ] `MKReverseGeocodingRequest` の async API 失敗時に既存の挙動と同じ「nil（住所のみ fallback）」または「住所取得失敗メッセージ表示」になる（ユニットテストで確認）。
- [ ] テスト最低 3 ケース追加: (a) 住所取得成功で 1〜3 件返る、(b) 0 件で nil、(c) ネットワーク失敗で nil。

## 技術メモ
- `MKReverseGeocodingRequest` は iOS 26 から提供される MapKit 系 API。`init(location:preferredLocale:)` または `init(coordinate:)` で構築し、`mapItems` プロパティで `MKMapItem` の配列を取得（async/await 対応）。
- 結果は `MKMapItem` 配列で返るため、Sprint 3 の `PlacemarkAddressFormatter` 相当を `MKMapItem.placemark`（CLPlacemark）または `MKMapItem.address` から組み立てる。Apple の API ドキュメントに合わせて変換層を 1 箇所に集める。
- `HomeRegistrationView` の連続呼び出しキャンセルは `Task` を `@State` で保持し、新規呼び出し時に `task?.cancel()` で実現する（`CLGeocoder.cancelGeocode()` の置き換え）。
- `PlaceLookupService` 側は `AppleGeocoder` のシグネチャ（`reverseGeocode(location:) async throws -> String?`）を維持。実装内部だけ `MKReverseGeocodingRequest` に差し替え、`PlaceLookupServiceTests` の既存 11 ケースが通るようにする。
- iOS 26 SwiftData ノート（.scrum/notes/ios26-swiftdata.md）と同様に、本作業を起点に **`.scrum/notes/ios26-api-changes.md`** を Sprint 4 開始前に新規作成（Sprint 3 retro Try）。S4-001 完了時にこのノートに「対応済」を追記する。
- iOS 26 専用 API のため `@available(iOS 26, *)` チェックは不要（プロジェクトの `IPHONEOS_DEPLOYMENT_TARGET` が 26 のため）。

## 平易な補足（jun さん向け）
iOS 26 で「住所を取得する古い仕組み」が非推奨になりました。Sprint 4 の最初に Apple 推奨の新しい仕組みに乗り換えます。Sprint 3 で出ていた「住所が表示される機能」と「ピンの場所名表示」はそのまま動き続けるよう、内部だけ差し替えます。Sprint 3 で残っていた 1 件のビルド警告がこれで消えます。
